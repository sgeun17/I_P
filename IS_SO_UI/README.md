# is so · 증적있소 UI

2026-10-10 현재 미리보기에 반영된 UI 전체입니다.

## 실행
1. 압축을 모두 풀어 주세요.
2. Python 3가 설치된 Windows에서 start_windows.cmd를 실행하세요.
3. 브라우저에서 http://127.0.0.1:8080 을 여세요.

Mac/Linux: 이 폴더에서 python3 start_local.py 실행.

## 수정할 파일
- dist/app.js: 화면 구성과 기존 UI 기능
- dist/finvera.css: 색상, 글꼴, 배치, 폴더 호버 효과
- dist/motion.js: 반복 스크롤 애니메이션
- dist/assets/: 로고와 이미지
- dist/index.html: 진입 페이지

기본 데모 모드에서는 예시 데이터로 검토 흐름을 확인합니다. 실제 분석은 연결 설정에서 백엔드를 연결해야 합니다. 백엔드·LLM·인증기준 데이터는 이 UI 압축파일에 포함되지 않습니다.
