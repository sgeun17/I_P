# Phase1 검색 마무리 점검 — 2026-09-27

WBS의 검색팀 작업은 13행 인증기준 KB, 14행 임베딩·벡터 DB, 15행 Retriever Top-K다. 전체 원문 대조에 이어 확장어 의미 검토, 경계 사례 검색, 저장소 DOCX 연결 검사 및 검수용 버전 기록을 수행했다. 최종 Phase1 완료 승인은 남아 있다.

후속 작업으로 일반 `retrieve()` 호출의 검색 프로세스·BGE-M3 재사용을 보완했다. 아래 표와 변경 범위는 앞선 KB·키워드 검토 작업의 기록이다. 최신 실행 코드 변경과 로딩 횟수 검사는 [BGE-M3 모델 재사용](9월27일_BGE모델_재사용.md)을 참고한다. 이전 검수용 스냅샷은 당시 버전으로 보존한다.

## Phase1 검색 완료를 위해 남은 것

1. **KB 최종 검수·범위 승인**: AI가 검토한 확장 키워드 878개, 특히 주의점 106개와 금융권 추가 요건 포함 범위를 사람이 승인한다. 보유 2023년 자료 대조를 최신 법규 검토나 사람의 최종 승인으로 표시하지 않는다.
2. **독립 정답 승인·실제 증적 평가**: 54개 세트는 합성 개발 자료다. 담당자가 정답을 승인하고, 별도로 확보한 실제 증적의 정답으로 검색 품질·실패 경계를 확인해야 한다. 기존 DOCX 6개의 연결 검사는 운영 출처 확인이나 정답 품질 평가를 대신하지 않는다. JSON의 `human_review`는 대기 상태다.
3. **입출력 규격 합의 및 실제 연동**: Top-5는 관련성 판단의 후보이며 similarity_score는 confidence나 충족 점수가 아니다. 이 의미와 오류 처리·PNG/JPG·OCR 출처 규칙을 담당 팀과 확정하고 실제 LLM 및 업로드·DB·화면 흐름을 검증한다.
4. **최종 버전 고정**: 위 내용·정답 검수 및 연동 결과를 반영해 최종 KB/색인/검색 설정 버전을 승인한다. 현재 두 `releases/phase1-review-2026-09-27*` 스냅샷은 검수용이다. 이전 스냅샷의 코드 해시는 당시 버전이며, 이번 평가 도구의 문서 수 표기 등 현재 버전 해시는 추가 스냅샷에 기록했다.

무관·정보 부족 문서도 Top-5 후보가 나오며 점수 범위가 관련 사례와 겹친다. 따라서 이번 작은 세트에 맞춰 운영 점수 임계값을 추가하거나 1위만 정답으로 선택하지 않았다. 고정 응답 연동 검사는 이미 통과했지만 실제 LLM의 무관·정보 부족·복수 후보 판정은 확인하지 못했다.

## 변경 범위

이번에는 `phase1_검색/tests/`에 원문·확장어 검토, 정답 근거·경계 사례 평가, 기존 DOCX 연결 검사 및 버전 기록 도구를 추가하고, 검색팀 결과·인계 문서를 기록했다. 기존 평가 도구의 보고 문서 수는 고정 30개에서 실제 입력 수로 표시하도록 보완했다. 운영 KB·검색/집계 알고리즘·임계값·입력팀·판단팀·Phase2 기준 코드 및 루트 문서 변경은 없다. 다른 두 팀의 기존 검증 대상 소스 43개 해시가 이전 연결 검사와 일치한다. 커밋·푸시·팀 메시지 발송은 하지 않았다.
