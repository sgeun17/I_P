# E0004 검색 후보 누락 재현

2026-10-06 서버 자료를 사용자 승인 후 개발/tmp/E0004_server_2026-10-06에 복사해 검증했다. 원문·청크·과거 응답은 Git 밖에 보존했다. 서버 파일과 다른 팀 코드는 수정하지 않았다.

## 확인 결과

원문은 2026년 정보보호 예산·인력 운영계획이며 전문인력 현황, 예산·자원 평가, 연간 추진계획을 담고 있다. 검색 관련성 검토 후보는 1.1.6 자원 할당이다. 이는 정답표 승인이나 Phase2 MET 판정이 아니다.

서버의 source_chunks.json 8개와 당시 search.json의 evidence_chunks가 동일하다. 현재 검색으로 당시 후보 1.1.3, 2.1.2, 1.1.2, 2.10.1, 1.3.1을 동일 순서로 재현했다. 당시 판단은 이 5개를 모두 NOT_RELATED로 처리해 NO_MATCH였고 Phase2가 건너뛰어졌다. 새 LLM 호출은 하지 않았다.

1.1.6은 청크별 순위가 1, 68, 2, 11, 1, 2, 41, 10이다. 8개 중 4개에서 Top-5지만 문서별 최대 유사도로 합친 최종 순위는 7위(최대 유사도 0.656249)라 후보 5개에서 제외됐다. 단일 청크에서 높은 점수를 받은 다른 통제항목들이 앞섰다. 근거가 없어서라기보다 검색 후보 집계에서 관련 항목이 누락된 사례다.
