# 검색 집계 변경 검증 결과

2026-10-06. 결론: 전체 평균·상위 3청크 평균으로 기본 집계를 일괄 교체하지 않는다. E0004 관련 항목은 회복하지만 다른 문서에서 관련 항목 누락이 재현됐다. 운영 코드·점수 의미·Top-5 계약은 유지했다. E0004 문제 자체가 해결된 것은 아니다.

| 방식 | 기존 개발 사례 15건 | E0004의 1.1.6 순위 | 추가 스트레스 사례 18건 |
|---|---:|---:|---:|
| 현재 최대 유사도 | 15/15 | 7위, 누락 | 18/18 |
| 전체 평균 | 15/15 | 2위 | 7/18 |
| 상위 3개 평균 | 15/15 | 4위 | 16/18 |
| RRF k=60 | 14/15 | 3위 | 3/18 |

표의 분수는 필요한 항목이 모두 Top-5에 포함된 문서 수다. 전체 정확도가 아니다. 기존 20건 중 5건은 확정된 관련 항목 라벨이 없어 분모에서 제외했다. E0004와 추가 18건을 포함해 총 39건을 검토했으며 34건에 예상 항목을 부여했다. 사람 승인 Gold가 아니며 추가 18건은 기존 사례의 변형이어서 독립 표본으로 간주하지 않는다. 추가 후보의 전체 정답 라벨이 없어 정밀도를 산출하지 않았다.

추가 사례는 유효 증적에 무관한 청크 6개를 덧붙인 15건과 한 주제 6청크·다른 주제 1청크로 구성한 3건이다. 결과를 보기 전에 기존 기대 항목을 그대로 유지했다. 반복 청크 시험은 문서 내 주제 비중에 대한 스트레스 시험이며 별도 실증적 18건이 아니다.

평균은 여러 청크의 지지를 받는 항목을 높이는 대신 한 청크에만 있는 중요한 항목을 낮출 수 있다. 현재 방식에서 찾던 항목을 전체 평균은 11건, 상위3평균은 2건에서 놓쳤다. 누락 목록과 순위는 aggregation_decision_2026-10-06.json에 기록했다.

## 반영한 작업

- tests/aggregation_stress_cases.json: 재실행 가능한 합성 18사례 추가.
- tests/test_aggregation_diagnostic.py: 소수 주제 근거가 평균 집계에서 누락되는 회귀 검사 추가. 진단 테스트 총 4개 통과.
- aggregation_stress_2026-10-06.json: 현재 BGE-M3·색인으로 실행한 실제 검색 비교 결과.
- 기본 집계·후보 수·임계값·판단팀 코드는 변경하지 않았다. 실제 LLM 호출도 하지 않았다.

## 다음 개선 조건

E0004 하나를 위해 통제항목 ID를 강제로 추가하지 않는다. 다음 개선은 최대 점수의 단일 근거 포착과 여러 청크의 반복 지지를 함께 사용하는 후보 선정으로 검토해야 한다. 이번 39사례에서 기존 방식 대비 누락이 늘지 않는지 확인하고, 추가된 후보의 관련성을 사람 검토해야 한다. 후보 수 또는 유사도 점수 의미를 변경하는 안은 판단팀의 입력 계약·검토 임계값과 함께 검증한다. 전체 평균으로 단순 변경하는 안은 이번 결과로 제외한다.
