# 이전 자료 보관

현재 실행에 사용하지 않는 210문항 중간본과 2장 범위 제안서를 보관한다. 삭제하지 않았으며 JSON 내용·버전·해시는 이동 전과 같다.

- `chapter2_batch1_checklist_draft.json`, `chapter2_batch1_review.md`: 13개 통제항목·210문항 작성 당시 자료
- `chapter2_scope_draft.json`, `chapter2_scope_review.md`: 전체 범위를 제안한 당시 자료

현재 사용할 기준은 상위 폴더의 [전체 700문항 JSON](../chapter2_full_checklist_draft.json)이다. 아직 사용 중인 기존 54문항 JSON은 이 폴더로 옮기지 않았다.

보관 JSON 내부의 상대 경로와 상위 버전의 `parent_draft` 등은 작성 당시 위치를 기록한 값으로 보존했다. 보관본을 과거 방식으로 재적재하려면 원래 `phase2_기준` 위치로 복원해 사용한다. 현재 실행기·검증기는 이 보관본을 입력으로 읽지 않는다.
