## 공통 판정 규칙

- 충족은 해당 대상·기간·사건에서 질문의 직접 근거를 확인한 경우다. 절차 존재와 실제 이행을 별도로 본다.
- 미충족은 적용 의무와 직접 위반 근거를 확인한 경우다. 자료를 못 받았다는 이유만으로 미이행을 확정하지 않는다.
- 판단불가는 자료 부족·대상/적용 기준/효력/기간 불명·판독 불가·미해소 상충인 경우다. 검토 사건 없음·의무 미도래·적용 제외 미합의도 포함한다.
- 충족·미충족에는 원문 인용이 필요하다. 일부 사건의 결과를 조직 전체로 확대하지 않는다.
- 조건부 질문은 아래 적용 조건부터 확인한다. 대상이 없다는 이유로 자동 충족 처리하지 않는다.
- critical은 모두 미정이고 팀·사람 승인을 부여하지 않았다.

## 현재 사용할 수 있는 범위

새 JSON은 기존 저장 모듈로 별도 버전에 적재·조회할 수 있는 질문 초안이다. 기본 체크리스트·사유 카탈로그·162개 가상 사례·LLM 연결을 새 버전으로 전환한 결과는 아니다. 기본 연결은 기존 3개 항목 버전을 유지한다. 신규 문항의 사유/사례 연결과 판단 입력의 버전 동기화는 다음 작업이다.

보유 2023년 KISA 일반 안내서의 주요 확인사항과 선택한 세부 조건을 대조했다. 금융권 추가요건과 세부 설명 전체를 구현한 최종본으로 간주하지 않는다. 길이·주기·보존기간·외부 인증 방식은 해당 대상·검토 시점의 적용 기준을 확인하며 예시 숫자를 일괄 적용하지 않는다.
