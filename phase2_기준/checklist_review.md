## 판정 시 주의할 경계

- 절차 수립과 실제 이행, 주기 설정과 주기 준수는 별도 조건이다.
- 2.5.1은 계정·권한 처리 건 자체, 2.5.6은 이력을 대상으로 한 주기적 검토와 후속조치를 확인한다. 같은 증적을 써도 자동으로 같은 판정을 복사하지 않는다.
- 보안책임 규정(Q13)과 개별 등록·권한부여 사건의 실제 고지(Q14)를 구분한다.
- 복구시험을 했다는 기록만으로 완전성·정확성·절차 적절성을 모두 확인했다고 처리하지 않는다. Q17~19는 확인 수행 여부이며 좋은 시험 결과나 복구 성공을 자동 보장하지 않는다.
- 소산 절차 준수와 중요정보 백업매체의 물리적 분리는 서로 다른 조건이다.
- 사건이 없거나 적용 여부를 모르면 MET으로 처리하지 않는다. 적용 제외 정책은 팀 합의가 필요하다.
- 근거 예시는 필수 파일명 목록이 아니며 required_context는 판정에 필요한 정보다. 특정 열 이름이나 문서 양식을 강제하지 않는다.
- 분기 검토 권고, 개인정보 접근권한 이력 보존기간, 금융권 백업 보존기간을 모든 대상에 일괄 적용하지 않는다. 적용 법규·기간의 현행성 검토는 이번 작업 범위 밖이다.
