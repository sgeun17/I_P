## E0004 추가 확인

아래 최초 검토 이후 서버에서 E0004 DOCX·8개 청크·과거 검색/판단 결과를 확보했고 검색 후보 누락을 재현했다. 따라서 아래의 E0004 자료 미확보 표시는 최초 검토 시점의 기록이다. 1.1.6이 청크 4개에서 Top-5인데 문서 최종 7위로 제외되는 것을 확인했다. 상세 결과는 [검색 재현 보고서](../../phase1_검색/reports/E0004_reproduction_2026-10-06.md)를 참고한다. E0012/E0023 자료·정답 승인 등 나머지 요청 상태는 유지한다.

## 확인 범위

사용자가 제공한 10/5 후속 요청 문서와 서버에서 복사한 phase2-current-r1-GhF06N의 25개 입력·audit·출력을 검토했다. 실행 기준은 3ba73a0, 저장된 Phase1 입력 재사용이다. 원본 PDF/XLSX 이미지·승인된 기대결과표·E0004 검색 입력은 포함되지 않았다. 원문 청크 및 개별 응답은 Git 밖 개발/tmp에 보존하고 저장소에는 조건 설명·합성 사례만 추가한다.

현재 기준은 101개·883문항 r6이다. r5의 3.3.2-Q02와 2.10.8-Q05 예외, critical 341/542, 사유 코드 13종은 유지한다. 새 버전은 아래 5개 문항의 인정 근거를 구체화한다. 질문·ID는 변경하지 않는다. 과거 실행의 미승인 경고가 현재 r6 승인 상태를 나타내지는 않는다.

## 검색팀

개발 사례 20건(예상 관련 항목이 있는 15건, 미라벨/무관 5건)으로 max/mean/top3 mean/RRF 집계를 비교했다. max·mean·top3 mean은 15/15건에서 필요한 항목 전체가 Top-5에 포함됐고, RRF는 14/15건이었다. 필요한 항목 기준 recall은 각각 18/18과 17/18이다. 라벨은 사람 미승인 개발용이다. 추가 후보의 정답 라벨이 없어 정밀도·불필요 후보 증가를 확정하지 않는다. 비교 근거만으로 운영 집계 방식은 변경하지 않았다.

보고서: phase1_검색/reports/aggregation_comparison_2026-10-06.json. E0004 원문이 없으므로 이 비교는 E0004 재현 완료가 아니다. 검색 입력 JSON(전체 청크)과 당시 검색 출력을 별도 제공받아야 한다.

다른 팀 코드·서버 설정·기존 실제 판정·정답표는 수정하지 않았다. commit/push 또는 외부 메시지 전송은 수행하지 않았다.
