## 판정 경계

- MET은 동일 대상·정보·접속경로·기간·사건과 당시 유효한 요구를 연결한 직접 근거가 있어야 한다. 정책 문서는 절차 수립을 확인하며 실제 설정·수행을 대신하지 않는다.
- NOT_MET은 적용 의무가 확인된 범위에서 미수립·생략·위반을 직접 확인한 근거가 있어야 한다. 자료 미제출이나 조회되지 않는 기록만으로 확정하지 않는다.
- UNKNOWN은 미제출·범위 불명·판독 불가·미해결 상충·사건 부재·의무 미도래·조건 또는 예외 적정성 미확인·적용 제외 미합의에 사용한다. 서로 다른 시점·대상의 자료를 단순 모순으로 보지 않는다.
- 원문·적용 법규의 요구를 내부 절차 준수만으로 충족했다고 대체하지 않는다. 2023년 법규표·시행유예·수치·알고리즘·설비·제품 예시를 현재 공통 의무로 고정하지 않는다.
- 실제 비밀번호·인증키·암호키·복구키와 전체 상세 네트워크·주소·배선 구조는 요구하지 않는다. 가상값 시험과 비밀값이 제거된 설정·메타정보·점검 결과를 사용한다.
- 한 통제의 MET을 다른 통제의 MET으로 자동 복사하지 않는다. 같은 근거를 공유해도 해당 대상·조건·시점·요구에 다시 대조하며 중복 가중치·최종 등급을 계산하지 않는다.

- 2.4.7-Q07: 잠금장치가 있는 안전한 장소에 실제 보관해야 MET이다. 동일 범위에서 잠금장치·안전한 장소 의무 위반이 직접 확인되면 실제 노출·유출 사건이 없어도 NOT_MET이다.
