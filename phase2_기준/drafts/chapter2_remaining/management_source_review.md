## 판정과 적용의 경계

- 절차 수립, 실제 이행, 기록을 구분한다. MET은 동일 대상·기간·사건과 당시 효력 있는 절차·기준에 연결된 직접 근거로만 판단한다.
- NOT_MET은 실제 적용 의무·시기와 확인된 미수립·생략·위반의 직접 근거가 있을 때만 가능하다. 자료 미제출·조회되지 않는 기록만으로 미이행을 확정하지 않는다.
- 미제출·판독 불가·미확인 적용성·예외·사건 없음·시기 미도래·해소되지 않은 동일 범위 상충은 UNKNOWN이다. 서로 다른 대상·효력 시점은 단순 상충으로 보지 않는다.
- 2.2.4-Q03은 보유 2023년 원문의 연 1회 이상 교육 조건을 보존한다. 적용 판본·범위·기간을 확인해야 하며 내부 임의 주기만 만족했다고 원문 조건까지 충족하지 않는다. 현행 법률의 고정 수치로 선언하지 않는다.
- 2.2.1의 수탁자 취급자 포함 범위, 2.2.2의 직무 분리 불가피성·보완통제, 2.2.4의 중요하지 않은 사안 공지 대체와 외부인력 교육, 2.3의 개인정보 위탁·국외 이전·재위탁·종료 시 회수·파기 조건을 확인해야 한다.
- 2.3.3은 교육 요청 공문이나 자체점검 결과 수신만으로 실제 이행 관리감독을 인정하지 않는다. 2.3.4는 파기 확약서만으로 실제 저장 범위 전체의 안전한 파기를 확정하지 않는다.
- 인력·서약·교육·징계 자료는 가명·마스킹한 식별 및 처리 메타정보로 검토한다. 실제 비밀번호·비밀값·불필요한 신상정보·서명 원본·중요정보 본문을 요구하지 않는다.
- 동일 근거를 다른 통제에서 공유해도 판정 결과를 자동 복사하거나 중복 가중치를 합산하지 않는다. 실제 증적·LLM·사람 승인·운영 저장·종합 등급은 수행하지 않았다.

- 주요 확인사항 2개와 종료·교체 공유, 물리 접근 회수, 공용계정 변경, 저장 범위·안전한 파기를 다룸. 계약 변경의 모든 유형·정보별 회수 방식·모든 매체별 파기 기술은 독립 질문으로 전부 확장하지 않음.
- 계약·법규에 따라 보관해야 하는 정보와 회수·삭제·파기 대상, 담당자 교체에 필요한 조치 범위는 당시 유효한 기준·의무·예외를 확인해야 함. 미확인 예외는 UNKNOWN.
- 방문·원격 확인·파기확약서 등의 방법 예시는 대상 매체·신뢰성에 맞게 검토하며 확약서 존재만으로 실제 파기 완료를 확정하지 않음.

다른 통제와의 경계:

- 2.2.5 퇴직·직무변경, 2.5.1 계정 말소·2.5.6 권한 검토와 동일 외부인 사건 근거가 겹칠 수 있으나 계약 종료·업무종료·교체의 범위·시기에 다시 대조하며 결과를 자동 복사하지 않는다.
- 2.2.3 서약·2.4 물리 접근 회수와 근거를 공유해도 외부자 종료 보호조치의 실제 이행을 따로 확인한다. 개인정보 파기 통제와도 동일 근거의 자동 결과 복사·중복 가중치 합산은 하지 않는다.
