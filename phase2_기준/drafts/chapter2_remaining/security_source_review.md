## 판정 및 적용 경계

MET은 동일 대상·기간·사건과 당시 유효한 기준을 직접 입증하는 근거가 있어야 한다. NOT_MET은 적용 의무와 수행 시점이 확인되고 실제 미이행·위반이 직접 확인된 경우에만 후보 판단이 가능하다. 미제출·조회 실패·누락된 서류만으로 실제 미이행을 확정하지 않는다. MET·NOT_MET에는 증적 인용이 필요하다.

UNKNOWN은 미제출·판독 불가·상충·범위 불일치, 유효 기준·예외·적용 조건 미확정, 사건 미발생 또는 기한 미도래 등에 사용한다. 사건 부재와 증거 부재를 구분한다. 최신 작성일만으로 충돌을 해소하지 않고 동일 대상·시점·버전·사건 연결을 확인한다. 클라우드·공개서버·전자거래·외부연계·모바일·공공기관 등의 미사용·미해당은 적용 제외 처리 합의 전까지 자동 MET이 아니다.

후보 증적은 값과 내용이 마스킹된 설정·권한·기존 시험결과·이벤트 메타정보·보고 또는 접수 기록이다. 실제 비밀번호·키·개인 고객정보나 기능적 공격을 요구하지 않는다. 공유 접근권한 비밀번호는 실제 값 없이 설정 상태를 확인하고, 대체 조치의 유효한 근거·승인·효과가 불명확하면 UNKNOWN이다.

2023년 원문의 사고 대응 모의훈련 연1회 이상 조건은 유지한다. 적용 판본·검토기간·의무·도래 기한을 연결하여 실제 수행을 확인한다. 훈련 계획·참여 공지·실제 사고 대응은 모의훈련 수행을 대신하지 않는다. 개인정보 사고 통지·신고 및 영향평가 제출의 2023년 수치·기한은 당시 유효한 법규와 독립 대조하며 현행의 모든 사건에 자동 적용하지 않는다.

RTO·RPO는 조직의 핵심 대상 중요도·특성에 맞게 정의한다. 임의의 보편적 복구 수치를 만들지 않았다. 복구 계획·자원 준비·백업 존재는 실제 사고 복구 또는 재해 복구 시험의 성공·목표 달성을 자동 입증하지 않는다. 시험 결과는 해당 대상·시나리오·실제 측정에 한정한다. 공개 중요정보의 노출은 원문의 즉시 차단 조건을 유지하며 인지·차단 시점을 직접 대조한다.
